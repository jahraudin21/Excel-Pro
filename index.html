Help & Keyboard Shortcuts

Getting started

Type a value or an =formula (e.g. =SUM(B2:B6)) into a cell or the formula bar. Everything auto-saves in your browser.

Keyboard shortcuts

Ctrl+C / X / VCopy / Cut / Paste
Ctrl+B / I / UBold / Italic / Underline
Ctrl+Z / YUndo / Redo
Ctrl+FFind & Replace
Ctrl+PPrint
Ctrl+F1Collapse the Ribbon
F2 · Enter · EscEdit cell · Confirm · Cancel
Ctrl+→ → → → →Jump to the edge of the data block
DeleteClear selected cells
