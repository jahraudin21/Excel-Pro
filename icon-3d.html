Excel-Pro app icon: 2D to 3D THREE.JS r160

Source: make_icon.py (green rounded tile + faint grid + bold white X, build/icon.ico). The tile is extruded 0.44 deep, grid lines become thin ribs, and the X becomes taller bars so the diagonals stay continuous - the same paint order as the 2D renderer. Drag to orbit, scroll to zoom, right-drag to pan. Regenerate with python make_icon_3d.py. Palette is same-to-same with the 2D pixels: tile #467221, grid #2f5118, X white. Measured front-view match vs make_icon.render(256): 100% of all 57,400 fully-opaque pixels (8 remaining diffs are alpha=128 half-blends no opaque geometry can reproduce).
